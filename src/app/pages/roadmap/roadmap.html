Roadmap

From first visit to first trace.

We are building toward a focused public MVP for Canadian Thanksgiving: one excellent guided P2PKH execution experience, backed by a clear and credible public project.

Public MVP October 12, 2026

Eight-week plan

A complete increment every week.

  1. Foundation
    Public identity

    Brand, organization, documentation, and frozen MVP scope.

  2. Weeks 2–3
    Public website

    Responsive pages, signup, hosting, domain, monitoring, and SEO.

  3. Weeks 4–5
    Trace engine

    Execution steps, stack snapshots, explanations, and failure diagnostics.

  4. Weeks 6–7
    Visualizer

    API integration, player controls, visual state, and a guided P2PKH lesson.

  5. Week 8
    Release candidate

    Accessibility, security, analytics, responsive QA, and launch preparation.

After launch

Learn. Build. Analyze.

Real transaction inspection, more script types, developer studios, market analysis, accounts, and commercial offerings follow only after the core learning experience is reliable.
