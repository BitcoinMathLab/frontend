Overview

An inspection layer for Bitcoin.

Bitcoin Math Lab turns serialized data, Script execution, stack transitions, and validation outcomes into experiences that can be inspected one decision at a time. The product is educational software: it does not hold keys, move funds, provide financial advice, or replace a fully validating Bitcoin node.

The first release follows one historical pay-to-public-key-hash spend. It includes a valid example, a deliberately altered signature, and a conceptual bridge from P2PK to P2PKH.

Architecture

Three repositories, explicit responsibilities.

Browser product

Frontend

The Angular application owns lessons, playback, visualization, accessibility, public pages, and browser monitoring. It consumes versioned product APIs; it does not reimplement Bitcoin rules.

Backend

Development principles

Correctness before spectacle.

  1. Show the mechanism. Prefer actual bytes, opcodes, and state changes over an analogy that hides them.
  2. Keep boundaries testable. Engine, API, and browser contracts are verified independently and together.
  3. Make failure educational. Invalid spends return inspectable traces and safe diagnostics, not raw exceptions.
  4. Stay honest about authority. Bitcoin Core remains the production source of truth for network validation.
  5. Ship narrow, complete increments. One polished P2PKH lesson comes before broad script or transaction coverage.

FAQ

Common questions.

Is Bitcoin Math Lab a wallet or node?

No. It is educational and developer software. The MVP uses curated transaction data and does not manage keys, broadcast transactions, or participate in the Bitcoin network.

Does Bitclone replace Bitcoin Core?

No. Bitclone makes selected mechanisms reusable and inspectable, while Bitcoin Core remains the production reference and network source of truth.

Why begin with P2PKH?

P2PKH is compact enough to follow in one sitting while still demonstrating stack data, hashing, equality verification, and signature checking.

Is the code open source?

Yes. The frontend, backend, and Bitclone repositories are public under the Bitcoin Math Lab GitHub organization.

Can I analyze any transaction?

Not in the first release. Real transaction lookup and broader script classification are planned after the curated visualizer is reliable in production.
