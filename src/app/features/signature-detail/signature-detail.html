Signature verification

How this signature is verified

  1. Build the message. Serialize the legacy signature preimage.
  2. Hash it. Apply SHA-256 twice to create the 32-byte digest.
  3. Decode the signature. Read DER integers r and s plus the hash type.
  4. Decode the public key. Recover the secp256k1 curve point.
  5. Verify ECDSA. Check the signature equation and push true or false.
